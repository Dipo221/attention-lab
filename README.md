# 注意力實驗室 Attention Lab

> 生成式 AI 導論 — 第五講〈AI 怎麼記得前面說過什麼？〉的互動版筆記
> 用 Vibe Coding 完成：先和 AI 討論出規格書，再請 AI 生成單一 `index.html`。

**線上 Demo：** https://你的帳號.github.io/attention-lab/

---

## 一、為什麼做這個

第五講把 Transformer 的核心公式整個推導了一遍：

```
Attention(Q, K, V) = softmax( QKᵀ / √dk ) V
```

但投影片上的公式是**靜止**的。我看得懂每一個符號，卻答不出幾個很基本的問題：

- 「注意力」具體長什麼樣子？一個字的注意力到底怎麼分給其他字？
- 為什麼要除以 √dk？不除會怎樣？「贏者通吃」有多誇張？
- 位置編碼為什麼要用 sin/cos？老師說「像時鐘指針」，可是我想不出畫面。
- 大家都說 RNN 不能平行化所以被淘汰，到底差多少？

這四個問題的共同點是：**講義給了答案，但沒給「改一個東西、看結果怎麼變」的機會。**
所以我把它們各做成一個可以動手拉的模組。

## 二、功能規格

### 模組 01 — Self-Attention 實驗室

| 項目 | 規格 |
|---|---|
| 輸入 | 自由輸入中英文句子，上限 12 個 token；另附 5 組範例一鍵帶入 |
| 斷詞 | 中日韓文字與全形標點逐字切；拉丁字母整個單字算一個 token |
| 可調參數 | `dk`（1–8）、head 數（1–4）、權重亂數種子（1–99） |
| 開關 | 「除以 √dk」、「causal mask」 |
| 視覺化 1 | **注意力流向圖**（SVG 弧線）：線寬與透明度正比於權重，每個字下方標百分比，可點擊換 query |
| 視覺化 2 | **權重長條圖**：選定 query 的完整分布、最大值標記、分布熵 |
| 視覺化 3 | **注意力矩陣熱力圖**：可切換「權重 α」與「原始分數 e」；hover 顯示該格的 e 與 α；點任一列換 query |
| 視覺化 4 | **算式拆解**：用畫面上的真實數字，逐步寫出 q→內積→÷√dk→mask→softmax→加權和 |
| 視覺化 5 | **Multi-head 縮圖牆**：每個 head 一張小熱力圖，點擊切換主畫面 |
| 視覺化 6 | X / Q / K / V 四個矩陣的色塊圖（可收合） |

### 模組 02 — softmax 與 √dk

- 五個分數用拉桿即時調整（範圍 −3 ~ 8），`dk` 可調 1–64
- 左右兩張長條圖同步比較「直接 softmax」與「÷√dk 後 softmax」
- 顯示**分布熵**與**最大佔比**，量化「有多集中」
- 四組預設：講義原例 / 差距超大 / 本來就很平均 / 隨機
- 預設值刻意採用講義那張表的數字（3.9, 3.2, 1, 0.3, 1.1），
  實際算出來就是講義上的 **61/30/3/2/4** 與 **40/29/11/8/11**

### 模組 03 — 位置編碼時鐘

- `t`（0–60）與維度 `d`（4–24）可調，並可按「讓時間走」自動播放
- `d/2` 個時鐘同步轉動，每個時鐘標出 k、對應維度、以及該頻率的**週期**
- 整張位置編碼表熱力圖（28 個位置 × d 維），目前的 `t` 那一列加外框
- **位置相似度曲線** ⟨p_t, p_t′⟩：顯示內積在 t′ = t 達到高峰、離越遠越低

### 模組 04 — RNN vs Transformer

- 句子長度 T（4–16）與每步耗時（80–500 ms）可調
- 兩條跑道同時跑同一句話：RNN 一格一格亮、Self-Attention 一次全亮
- 即時顯示步數、模擬耗時，結束後給出倍數結論
- 對照表同時誠實列出代價：Transformer 步數 1 步，但內積次數是 **T²**

## 三、技術規格

| 項目 | 內容 |
|---|---|
| 檔案結構 | 單一 `index.html`，CSS 與 JavaScript 全部內嵌 |
| 相依套件 | **零**。沒有 CDN、沒有外部字型、沒有圖片，斷網也能跑 |
| 矩陣運算 | 純手寫 JS：`matmul`、`transpose`、`softmax`、`entropy`，常態亂數用 Box–Muller |
| 繪圖 | 熱力圖用 CSS Grid；流向圖、時鐘、折線圖用手寫 SVG（無 canvas、無圖表函式庫） |
| 決定性 | FNV-1a 字串雜湊 + mulberry32 PRNG。同一個字永遠得到同一個 embedding，同一個種子永遠得到同一組權重——重新整理結果不會跳動 |
| 數值設定 | `d_model = 8`；embedding 做 L2 normalize、W 用標準常態初始化，使 q、k 分量約為 unit variance |
| 狀態保存 | 句子與所有設定存在 `localStorage` |
| 介面 | 深／淺色主題、桌機與手機自適應、`prefers-reduced-motion` 支援 |

## 四、一個重要的誠實說明

這裡的 W^Q、W^K、W^V 是**隨機初始化、沒有訓練過**的，
token embedding 也是用字串雜湊生出來的，不是真的語意向量。

所以**請不要**從這裡的注意力分布去解讀「AI 覺得『貓』跟『追』有關係」——那沒有意義。

這個工具展示的是**運算的流程與形狀**：矩陣怎麼相乘、softmax 怎麼把分數變成機率、
√dk 怎麼影響分布的集中程度、causal mask 怎麼把矩陣右上角切掉。
要有語意，得餵真正訓練好的權重，那就不是一個單檔 HTML 塞得下的東西了。

我認為把這件事寫清楚，比讓它看起來很聰明重要。

## 五、怎麼玩（建議順序）

1. 模組 01 輸入一句話，**點任一個字**把它設成 query，看流向圖
2. 把「除以 √dk」**關掉** → 熱力圖立刻變得黑白分明，這就是贏者通吃
3. 打開 **causal mask** → 右上三角整片變「–」，decoder 就是這樣遮住還沒生成的字
4. head 數拉到 4 → 四張縮圖長得完全不一樣，這就是 multi-head 的意義
5. 模組 03 按「**讓時間走**」→ 左邊指針飛快轉、右邊幾乎不動
