    Module 02

    為什麼要除以 √dk？

    內積算出來的分數如果差距太大，softmax 會變成「贏者通吃」——第一名吃掉 6 成，其他人幾乎被忽略。 除以 √dk 把分數壓平一點，注意力才分得開。下面的五個分數可以自己拉。

    5
    直接 softmax(e)
    softmax(e / √dk)
    兩者差多少

    Module 03

    位置編碼時鐘

    Self-Attention 本身看不出字的先後順序，所以要在 embedding 上加一個「位置向量」。 原論文的做法：把維度兩兩一組當成一根時鐘指針，θ = ωk · t，從 12 點開始順時鐘走。 前面的指針走得快（像秒針），後面的走得慢（像時針）。

    0
    12
    ωk = 1 / 100002k/d　　p2k = sin(ωkt)　　p2k+1 = cos(ωkt)
    每一對維度 = 一根指針
    整張位置編碼表列＝位置，行＝維度

    左邊幾行變化很快，越往右越慢——這就是「個位數、十位數、百位數」的感覺。 目前的 t 那一列會有外框。

    位置之間有多像⟨pt, pt′⟩

    兩個位置的內積在 t′ = t 最高，離越遠越低。模型因此可以感覺到「相對距離」。

    第五講的公式（softmax(QKᵀ/√dk)V）在投影片上是靜止的： 看得到式子，但看不到「改一個東西，結果會怎麼變」。

    ⚠ 一個重要的誠實說明

    這裡的 WQ、WK、WV 是隨機初始化、沒有訓練過的， token embedding 也是用字串雜湊生出來的，不是真的語意向量。

    所以——請不要從這裡的注意力分布去解讀「AI 覺得『貓』跟『追』有關係」，那是沒有意義的。 這個工具要展示的是運算的流程與形狀：矩陣怎麼相乘、softmax 怎麼把分數變成機率、 √dk 怎麼影響分布、mask 怎麼把右上角切掉。

    要有語意，得餵真正訓練好的權重——那就不是一個 8 KB 的 HTML 檔塞得下的東西了。 我覺得把這件事講清楚，比假裝它很聰明重要。

    用法小抄

    3. 打開 causal mask，右上三角會整片消失：decoder 就是這樣遮住還沒生出來的字。
    4. 拉 head 數 到 4，看下面四張縮圖長得完全不一樣。
    5. 去模組 03 按「讓時間走」，看左邊的指針飛快轉、右邊的幾乎不動。
